# Contributing

В проекте стиль Python-кода проверяет [Ruff](https://docs.astral.sh/ruff/): он же линтер и форматтер. [pre-commit](https://pre-commit.com/) запускает обе проверки локально перед `git commit`.

Версии зафиксированы в `requirements-dev.txt`: `ruff==0.17.1`, `pre-commit==4.7.0`. Правила линтера и форматтера лежат в `pyproject.toml`, список хуков — в `.pre-commit-config.yaml`.

## Установка

Команды выполняются из корня репозитория. Нужен Python 3.8+.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
pre-commit install
```

`pre-commit install` записывает хук в `.git/hooks/pre-commit`. После этого проверки стартуют сами при коммите. Виртуальное окружение `.venv` в git не попадает.

## Проверка и форматирование

Посмотреть замечания линтера:

```powershell
ruff check .
```

Исправить то, что Ruff умеет править сам (порядок импортов, лишние пробелы, часть устаревшего синтаксиса):

```powershell
ruff check . --fix
```

Отформатировать код:

```powershell
ruff format .
```

Проверить форматирование, не меняя файлы:

```powershell
ruff format . --check
```

Прогнать те же хуки, что и перед коммитом, по всем файлам:

```powershell
pre-commit run --all-files
```

Один файл или каталог можно передать вместо `.`, например `ruff check Aptamer-Generation`.

## Что происходит при коммите

Хук выполняет два шага:

1. `ruff-check --fix` — линтер с автоисправлением.
2. `ruff-format` — форматтер.

Если хук изменил файлы, коммит прерывается. Нужно просмотреть правки, добавить их в индекс и повторить коммит. Если замечание нельзя исправить автоматически, Ruff печатает файл, код правила и строку — правьте код и коммитьте снова.

## Какие правила включены

В `pyproject.toml`:

| Настройка | Значение |
| --- | --- |
| Версия синтаксиса | Python 3.8 |
| Длина строки | 100 |
| Наборы правил | `E`, `W` (pycodestyle), `F` (pyflakes), `I` (isort), `UP` (pyupgrade), `B` (bugbear) |
| Исключено | `E501` — длина строки отдельно не валит проверку, переносы делает форматтер |
| Кавычки | двойные |
| Отступ | пробелы |

`Aptamer-Validation/Snakefile` в проверку не входит: это Snakemake, а не обычный Python. CSV, веса моделей, MDP-файлы и прочие не-Python файлы Ruff тоже не смотрит.
